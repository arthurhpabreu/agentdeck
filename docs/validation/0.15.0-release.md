timeout's cause was not established; these results do not establish that it
has been fixed. The third preview passed all Windows native tests and both
platform packaging/smoke jobs.

five successful native helpers and a live GUI after twenty seconds. Their
desktop screenshots were inspected and fit their screen work areas.

## Validation limits

Interface tests mock the native Tauri/provider boundary. Native tests exercise
controlled protocol messages, files, SQLite and processes; no paid model turns
were submitted. Packaged Mac smokes establish startup, native-helper behavior
and initial window state, rather than complete authenticated provider flows.
No Windows clean-machine installation or upgrade was performed.

Windows installers are unsigned. The Mac release packages were ad-hoc signed
and not Apple-notarized. These checks do not substitute for Authenticode,
Developer ID signing or Apple notarization. No global authentication profile
was selected, cleared or replaced during publication work.
