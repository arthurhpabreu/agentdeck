## Packaged applications

The release builds Windows x64 NSIS and MSI installers, plus one universal macOS application containing both arm64 and x86_64. The same Mac bundle is launched on Apple Silicon and Intel; native statusline/Unicode socket helpers, twenty-second startup, crash diagnostics and visible window bounds are checked. Mac signing is ad-hoc and is not Apple notarization. Windows installers remain unsigned.
