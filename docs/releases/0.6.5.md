Agent Deck 0.6.5 improves long conversations, terminal visibility and the reliability of local memory and workspaces.

- **More visible agent activity:** tool cards show commands, working directories, available output and exit status. Quiet turns expose process checks and stop controls; heartbeats remain distinct from meaningful progress.
- **More reliable long chats:** streaming updates are batched, completed tools are archived during long turns, and late output or missed completion events can be recovered. Slow context compaction reports its state and keeps waiting for provider confirmation.
- **Compact composer:** commands and skills sit above the input; model, effort, mode, access, attachments and response actions share one row.
- **Memory and Obsidian diagnostics:** source health reports unavailable vaults and partial indexes without hiding healthy search results. Context sources show the selected excerpts and whether they were prepared or delivered.
- **Safer workspace recovery:** preserved worktrees remain discoverable after removing a project or restarting. Cleanup requires confirmation, checks for local files and active processes, and retains the Git branch.
- **Draft protection:** editor saves preserve typing during pending writes, unsaved tabs require confirmation, memory drafts survive panel navigation, and exports keep their validated destinations.
- **Documentation:** the main README now focuses on the product and setup; version-specific changes stay in release notes.

Validation: 136 browser tests and 159 Rust tests passed locally; six optional integration tests remain ignored. The release executable passed 12 isolated memory MCP scenarios with 36 RPC requests and no model calls.

Close Agent Deck and install over your current version using the same package type (`.exe` or `.msi`). The in-app updater detects published stable releases. `SHA256SUMS.txt` covers both installers and `LICENSE`.

Installers are unsigned. Browser tests mock native provider boundaries; this release does not claim a clean-machine interactive upgrade or live paid provider validation. Claude tool visibility is limited to progress and results exposed by its CLI. Context delivery does not prove that a model used a source.
