Agent Deck 0.6.8 improves long conversations and recovery in Codex and Claude Code.

- **Adaptive context management:** automatic compaction considers the next request,
  goal and attachment paths. When the provider reports its model window, Agent Deck
  reserves room for replies and tools. Window pressure bypasses the interval after
  compaction; oversized requests and live follow-ups stay editable.
- **New chat with context:** use the arrow in the chat header or the action in
  **Conversation context** to prepare a separate conversation. The original chat
  stays available. The new draft preserves the goal, settings and working directory,
  includes selected history excerpts and references the complete local archive.
  Review and send it when ready; preparing the continuation does not start a task.
- **Large history support:** continuation archives retain all locally recorded
  messages, tools and attachment references. Large archives use lossless byte parts
  and a manifest instead of putting the entire transcript into the new prompt.
  History pages also bound rendered text, so loading many large responses no longer
  requires laying out the whole batch at once. Earlier messages remain accessible.
- **More reliable Codex connections:** native thread resume excludes full-history
  payloads. OAuth/MCP warnings and provider retries are separate from fatal errors,
  preserve work state and no longer reset meaningful-activity timers.
- **Safer recovery:** connection setup, stalled compaction and unconfirmed input
  acknowledgments have deadlines. Ambiguous acceptance prepares a continuation
  request instead of automatically replaying work. A lingering transport closes
  after confirmed completion while active model turns and tools remain preserved.

Automatic compaction in the existing chat remains the default for ongoing work.
A separate chat receives excerpts plus an archive it can consult; it does not load
every prior token or reconstruct hidden provider state. The archive includes the
history captured by Agent Deck, with any existing truncation markers. External
integration logins, such as Miro, still need reconnection when their credentials
expire. See the [context and recovery guide](https://github.com/arthurhpabreu/agentdeck/blob/v0.6.8/docs/context-compaction.md).

Validation results and limits are recorded in the [validation evidence](https://github.com/arthurhpabreu/agentdeck/blob/v0.6.8/docs/validation.md#068).
Browser scenarios use mocked desktop commands; live provider authentication and
clean-machine installation are separate checks.

Close Agent Deck and install over your current version using the same package type
(`.exe` or `.msi`). Release assets include both Windows x64 installers alongside
`LICENSE` and `SHA256SUMS.txt`. Installers remain unsigned.
