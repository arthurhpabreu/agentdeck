# Agent Deck 0.6.0

## Commands and skills

Commands and skills are now available in structured chat, native startup prompts,
and terminal follow-ups. Type `/`, use `$` for Codex skills, or open the searchable
picker. Suggestions show descriptions, their source, and terminal requirements;
select with the arrows and Enter/Tab, then add arguments before submitting.

The app discovers existing user/project definitions, enabled Claude plugin
definitions, native Codex skills, and Gemini extension files. Refresh the picker
after installing or editing definitions. Discovery does not submit model prompts.

Structured chat controls support `/model`, `/effort`, `/fast`, `/plan`, `/code`,
and `/status`. Claude's supported non-interactive commands stay in chat. Codex
skills use explicit native skill input; terminal-only commands open the existing
session in its native CLI. Unknown slash commands keep the draft and show an error.

## Windows downloads

- `Agentdeck_0.6.0_x64-setup.exe`: interactive installer.
- `Agentdeck_0.6.0_x64_en-US.msi`: MSI package for the same app.
- `SHA256SUMS.txt`: download checksums.
- `LICENSE`: complete current terms.

Windows x64 installers are unsigned. No personal settings or provider credentials
are included. Each user installs an official supported agent CLI and signs in
with their own provider account. See the setup guide for prerequisites.
