# Agent Deck 0.12.0

This update puts every project's agents one click away: sessions no longer sit
below a long project list, and choosing a project takes you straight into its
conversation.

## Changes

- **Projects beside their sessions:** in a wide sidebar, projects and the
  sessions of the selected project appear side by side, each with its own
  scrolling. In a narrow sidebar they stack, with projects limited to about 40%
  of the height so sessions stay in view. Widen the sidebar to see them side by
  side.
- **One click to switch projects:** selecting a project, in the sidebar or in
  quick navigation, opens its conversation that needs you, otherwise the last
  one you opened there. A project without sessions opens a new session.
- **Sessions that sort themselves:** pending approvals and questions, waiting
  and running sessions come first, followed by the most recent activity. Each
  session shows when it was last active and any unread approval, question,
  error or finished response.
- **Room for many agents:** sessions idle for more than seven days that you have
  not opened recently fold under **Show older sessions**; the five most recent
  always stay visible.
- **A tidier sidebar:** **Preserved worktrees** became an archive button with a
  counter next to **Projects**, the new conversation folder became a one-line
  choice with its explanation in the tooltip, and adding a project opens a
  dialog.

## Downloads

- **macOS Apple Silicon and Intel:** `Agentdeck_0.12.0_universal.dmg`, or
  `Agentdeck_0.12.0_universal.app.tar.gz`.
- **Windows x64:** `Agentdeck_0.12.0_x64-setup.exe` or
  `Agentdeck_0.12.0_x64_en-US.msi`.
- `SHA256SUMS.txt` lists checksums for the four packages and `LICENSE`.

Close Agent Deck before installing over the current version. On Windows, use the
same installer type (`.exe` or `.msi`).
