# Agent Deck 0.10.0

This update simplifies workspace organization and knowledge setup, and adds
optional task distribution across models while preserving your main agent settings.

## Changes

- **Hold and drag:** move items by holding their body, with the dotted grips
  removed from lists, tabs, cards and widgets. Regular clicks, text selection,
  inputs, links and action buttons keep their functions. Touch scrolling,
  keyboard rearrangement, cancellation and undo remain available.
- **Wider sidebar:** resize the left sidebar up to half the window width using
  the pointer or keyboard. The saved preference adapts to smaller windows.
- **Clearer knowledge setup:** Documents opens first, with search ahead of
  optional graphs and diagnostics. **Sources** for a project or conversation
  are separate from the **Vault catalog**; registering a vault keeps its use an
  explicit choice. Paths, restrictions and advanced settings sit inside details,
  preserving existing inheritance and empty selections.
- **Quieter MCP diagnostics:** optional startup OAuth refresh messages, including
  Miro, appear as sanitized execution details. Explicit authentication failures
  for a requested action remain visible and actionable.
- **Independent model distribution:** enable **Distribute tasks across models**
  in Token economy without installing RTK. Your chosen main model, effort, Fast
  and Ultra remain in effect, and the existing controls stay usable. The option
  applies to future runs; agents already running keep their settings.
- **Bounded exploration and advice:** available Luna models handle Codex
  exploration at low effort, with Astra or Sol providing occasional advice at
  high effort. Claude Code uses Haiku for bounded read-only queries and Opus for
  occasional review. Native Opus advice is limited to explicitly selected,
  known-compatible model pairs; default, custom and Fable selections use a
  read-only Opus reviewer with a short brief, preserving the main model.

Model distribution has **no savings estimate yet**. Provider-reported usage and
RTK measurements remain separate; advisor calls add token usage, and savings
depend on the tasks and models actually used.

## Downloads

- **macOS Apple Silicon and Intel:** `Agentdeck_0.10.0_universal.dmg`, or
  `Agentdeck_0.10.0_universal.app.tar.gz`.
- **Windows x64:** `Agentdeck_0.10.0_x64-setup.exe` or
  `Agentdeck_0.10.0_x64_en-US.msi`.
- `SHA256SUMS.txt` lists checksums for the four packages and `LICENSE`.

Close Agent Deck before installing over the current version. On Windows, use the
same installer type (`.exe` or `.msi`).
