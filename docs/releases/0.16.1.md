# Agentdeck 0.16.1

This release fixes two cases where chat could appear stuck while the agent
was writing or had already finished.

## Changes

- Reopen a conversation to see the reply in progress or the reply that
  finished while you were in the editor. Scroll up to read earlier messages
  at your own pace.
- Use the down-arrow button to return directly from search or an archived
  page to the live conversation. Keyboard focus returns to the transcript.
- Agentdeck checks the native process when you return to the window and
  recovers recent reply text and completion status if an update was missed.
  You can see the result without sending another prompt.
- When the agent switches from a command to writing a reply, the activity
  indicator updates while the command's details remain available in the chat.

## Downloads

- Windows x64 users can choose `Agentdeck_0.16.1_x64-setup.exe` or
  `Agentdeck_0.16.1_x64_en-US.msi`.
- For Apple Silicon and Intel Macs, download `Agentdeck_0.16.1_universal.dmg`
  or `Agentdeck_0.16.1_universal.app.tar.gz`.
- `SHA256SUMS.txt` covers the four packages and `LICENSE`.

Close Agentdeck before updating. On Windows, use the same installer type as
your current installation.
