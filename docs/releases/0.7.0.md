# Agent Deck 0.7.0

Agent Deck now ships for Windows and macOS from the same repository, with one version and one release. The universal macOS application supports Apple Silicon and Intel and targets macOS 11 or newer with Safari/WebKit 16.4+. Install available system and Safari updates on older Macs. Native CI and packaged startup are exercised on macOS 15.

## Downloads

- **macOS:** `Agentdeck_0.7.0_universal.dmg`. Open it and drag Agentdeck into Applications. The universal `.app.tar.gz` contains the same application as an alternative.
- **Windows x64:** `Agentdeck_0.7.0_x64-setup.exe` or `Agentdeck_0.7.0_x64_en-US.msi`.
- **Verification:** `SHA256SUMS.txt` covers all four packages and `LICENSE`.

The Mac package is ad-hoc signed and **not Apple-notarized**. On first launch, Gatekeeper can require **System Settings → Privacy & Security → Open Anyway** after attempting to open the installed app. Follow [Apple's instructions](https://support.apple.com/en-us/102445). Windows installers remain unsigned.

## macOS behavior

- Native platform detection, login-shell terminals, Command shortcuts and UTF-8 clipboard handling preserve terminal Ctrl+C interruption.
- macOS window controls, multi-monitor positioning and close-to-tray behavior; quitting ends the application. Startup/restored windows fit the available screen area, including the menu bar and Dock.
- CLI discovery includes common Homebrew/user installation locations, with consistent executable/Node PATH for chat, terminals, runners, catalogues and updates.
- Native hook and statusline helpers use the app executable; Python is not required.
- Claude's Keychain credentials remain with its official CLI. Usage can use current provider/statusline reports without treating a missing credentials file as logout.
- App updates select the universal DMG, verify its checksum/structure and open it for manual installation with localized instructions.

## Shared architecture and release process

Platform adapters and separate Tauri overlays keep the core workspace shared. SemVer synchronization and tag validation cover the frontend, Tauri configuration and Rust manifests. CI validates Windows, Apple Silicon and Intel; packaged Mac checks verify both architectures, the minimum OS, license, metadata and signature, then launch the same universal app on both kinds of Mac.

This version includes the long-conversation continuity, bounded history rendering and connection recovery improvements from 0.6.8. Provider authentication and service failures still require recovery in the official CLI or service when credentials expire.

Integration authentication warnings now appear briefly when a new error arrives and disappear automatically. Repeated status updates and previously saved warnings do not keep the banner on screen. Fatal task errors still remain available for recovery.
