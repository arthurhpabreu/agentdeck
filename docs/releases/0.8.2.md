# Agent Deck 0.8.2

Released 2026-10-15.

This patch fixes Claude Code conversations ending while background work was still running.

## Changes

- **Background work finishes:** Agent Deck waits for Claude Code's native process to exit, so commands, renders and agents can finish and report their results. Previously, a ten-second cleanup after a response could terminate that work. The cleanup now applies only to completed Codex transports.

To continue work interrupted before this update, reopen the original conversation and send a follow-up. Its history and resumable provider session remain available.

## Downloads

- **macOS Apple Silicon and Intel:** `Agentdeck_0.8.2_universal.dmg`, or `Agentdeck_0.8.2_universal.app.tar.gz`.
- **Windows x64:** `Agentdeck_0.8.2_x64-setup.exe` or `Agentdeck_0.8.2_x64_en-US.msi`.
- `SHA256SUMS.txt` lists checksums for the four packages and `LICENSE`.

Close Agent Deck before installing over the current version. On Windows, use the same installer type (`.exe` or `.msi`).
