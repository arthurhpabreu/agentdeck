# Agentdeck 0.13.0

This release improves long conversations, large follow-up prompts and native
subagent tracking. Chats in the same project can now coordinate through a shared
activity board and short inbox messages.

## Changes

- **Large additional input:** initial prompts and additional input accept up to
  2 MiB of UTF-8 text. Conservative token estimates remain advisory; the provider
  determines whether its context window can accept the request. Larger reference
  text can be attached as a file.
- **Responsive conversations:** provider input uses a bounded background writer,
  preventing large messages and tool output from blocking one another. Large
  Unicode pastes use controlled insertion, and lengthy user messages can be
  expanded on demand while their complete content stays saved.
- **Clearer recovery:** process exit alone no longer counts as success. Missing
  confirmations, protocol failures and interrupted delivery remain visible;
  newer drafts survive startup, cancellation and follow-up transitions. Confirmed
  completion preserves intentional background processes.
- **Codex and Gemini subagents:** the agent monitor uses native lifecycle events
  and persisted session relationships to show hierarchy, activity and status.
  Tracking depends on evidence recorded by the installed CLI.
- **Project chats:** open **Project chats** to see peer activity and worktrees,
  publish a short handoff or send a note. Agents can use the same scoped MCP
  tools. Notes stay in the recipient inbox and do not automatically execute work.
  Coordination can be disabled per chat; other projects and full transcripts are
  not included.
- **RTK and model distribution together:** separate indicators clarify their
  independent settings. Claude configuration overlays preserve hooks,
  permissions, instruction files and worktree-relative paths. Repeated launches
  avoid duplicate guidance. Delegation guidance favors bounded summaries and
  reuse of relevant evidence. Model distribution may lower cost per task;
  additional agents can still increase total token consumption.

## Downloads

- **Windows x64:** `Agentdeck_0.13.0_x64-setup.exe` or
  `Agentdeck_0.13.0_x64_en-US.msi`.
- **macOS Apple Silicon and Intel:** `Agentdeck_0.13.0_universal.dmg`, or
  `Agentdeck_0.13.0_universal.app.tar.gz`.
- `SHA256SUMS.txt` covers all four packages and `LICENSE`.

Close Agentdeck before installing over the current version. On Windows, use the
same installer type (`.exe` or `.msi`).

Protocol and UI tests do not establish live authenticated provider behavior or
measured total-token savings. See the [conversation reliability audit](../validation/2026-10-20-conversation-reliability.md)
for the findings, regression coverage and remaining limits.
