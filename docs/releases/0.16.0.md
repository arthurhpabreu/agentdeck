# Agentdeck 0.16.0

Chat alerts that match what the agent is doing, approvals and interrupts that
work like Claude Code and Codex, and CLI sign-ins that stay valid.

## Changes

- **Truthful alerts:** a finished turn shows as complete instead of "waiting
  for interaction". A tool the agent was not allowed to use no longer raises
  "error to review" while it keeps working, and opening a chat clears the
  errors it shows. A live process that is quiet during a long build or test is
  shown as a long step, not a stall.
- **Claude Code approvals in chat:** with full access off, tool approvals,
  plan review and the agent's questions appear in the chat instead of being
  denied. "Approve for this session" applies the rule Claude suggests, and an
  approved plan leaves plan mode.
- **More Codex approval choices:** approve once or for the session, decline and
  continue, or decline and stop. Extra sandbox permission requests and
  approvals from subagents reach you; MCP forms the chat cannot show no longer
  end the turn.
- **Stop like the CLIs:** Stop and Escape interrupt the turn natively and show
  "Interrupting…"; a second Stop or Escape ends the process at once. A message
  sent as a turn finishes starts the next turn instead of failing.
- **Sign-ins stay valid:** background checks for commands and models no longer
  kill the CLI while it may be renewing its login token, run less often, and
  Agentdeck never rewrites an unreadable Codex or Claude settings file.
- **Composer and transcript:** Up/Down recall earlier prompts, `@` inserts a
  project file path, and edits show their file and a red/green diff.
- **Safer project removal and clearer setup:** removing a project asks for
  confirmation with its chat count. A missing CLI or expired sign-in offers
  Install or Sign in again. Settings has an Agents tab; the provider, model and
  effort chosen in a chat become the default for new chats.
- **Native terminals:** a Claude permission dialog appears in "Needs you" until
  you answer it in the terminal.

## Behavior notes

Claude chats without full access now pause for your approval, as Claude Code
does, instead of skipping restricted tools. Plan mode and full access stay per
conversation.

## Downloads

- **Windows x64:** `Agentdeck_0.16.0_x64-setup.exe` or
  `Agentdeck_0.16.0_x64_en-US.msi`.
- **macOS Apple Silicon and Intel:** `Agentdeck_0.16.0_universal.dmg` or
  `Agentdeck_0.16.0_universal.app.tar.gz`.
- `SHA256SUMS.txt` covers the four packages and `LICENSE`.

Windows installers are unsigned. macOS packages use the existing signing setup;
without Developer ID credentials they are ad-hoc signed and not Apple-notarized.

Close Agentdeck before updating. On Windows, keep the same installer type.
