# Agent Deck 0.11.0

This update makes it obvious which projects need you, reclaims the disk space
held by old session worktrees and makes completion notifications open the right
conversation.

## Changes

- **Projects that organize themselves:** the project list groups projects into
  **Waiting for you**, **Running**, **Recent** (activity in the last seven days)
  and **Other projects**. Each project shows its most urgent pending action, the
  running task or when it was last active, with a status dot. Click a group
  header to collapse it; the choice is remembered. Other projects keeps your
  manual arrangement.
- **Clean all worktrees:** **Preserved worktrees** now opens on the current
  project and offers **Clean all**, which removes every worktree that is not in
  use or locked after one confirmation, showing progress and the space freed.
  Your work stays recoverable in Git: commits remain on their branches,
  uncommitted changes go to the repository's `git stash` (`git stash list`), and
  commits without a branch get an `agentdeck/archive/*` branch. Dependencies,
  builds and other files ignored by Git are deleted.
- **No more accumulated worktrees:** removing a session archives its worktree the
  same way, instead of keeping the whole folder whenever it contained
  `node_modules` or build output.
- **Notifications that open the session:** on Windows, clicking a completion
  notification now opens the finished conversation and switches to its project.
  The notification title names the project.
- **Quieter error panel:** the browser's "ResizeObserver loop" warning no longer
  appears as a frontend error, and the list measurement that triggered it was
  fixed.
- **Simpler lists:** the display density selector was removed; lists use the
  comfortable layout.

## Downloads

- **macOS Apple Silicon and Intel:** `Agentdeck_0.11.0_universal.dmg`, or
  `Agentdeck_0.11.0_universal.app.tar.gz`.
- **Windows x64:** `Agentdeck_0.11.0_x64-setup.exe` or
  `Agentdeck_0.11.0_x64_en-US.msi`.
- `SHA256SUMS.txt` lists checksums for the four packages and `LICENSE`.

Close Agent Deck before installing over the current version. On Windows, use the
same installer type (`.exe` or `.msi`).
