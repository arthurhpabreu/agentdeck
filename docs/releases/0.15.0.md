# Agentdeck 0.15.0

Schedule recurring prompts from your chat, keep execution and approval states
consistent, and inspect agent flows at a readable scale.

## Changes

- **Prompt schedules:** use the calendar button in a Codex or Claude Code chat
  to save a prompt, time, weekdays, inclusive start/end dates and timezone.
  Pause, resume or remove schedules without losing your chat draft.
- **Reliable execution states:** terminal waiting notifications and old process
  exits no longer mark an active chat as waiting or complete. Missing native
  completion and approval events can be recovered without resending a prompt.
- **Approvals inside Codex chat:** command/file approvals wait for your decision.
  Decline and stop sends the native cancel decision. Optional questions clearly
  explain when the agent can continue working. Denied actions are distinct from
  pending approvals, and the sidebar, status bar and agent monitor agree.
- **Readable agent maps:** the map opens on the selected conversation, with
  direct agent navigation, wheel panning, a 100% zoom control and zoom preserved
  on resize. Filters frame their own results. Manual positioning preserves the
  real delegation hierarchy.
- **Open chat counts:** every project shows its number of open chats.
- **Less repeated work:** unchanged message rows are reused during typing and
  streaming; transient status and heartbeat updates do not write unchanged chat
  history. Development watchers ignore generated local and test artifacts.

## Scheduling behavior

Agentdeck must stay open and the computer must be awake. A busy chat can delay
an occurrence by up to fifteen minutes; older occurrences are recorded as missed
and are not replayed in a batch. Failed or uncertain dispatch is not retried
automatically. Schedules keep their saved timezone, pause when the destination
changes and are removed when the chat is deleted.

Schedules use the conversation's current agent settings. The scheduled text is
saved without attachments, and the user's draft is preserved.

## Downloads

- **Windows x64:** `Agentdeck_0.15.0_x64-setup.exe` or
  `Agentdeck_0.15.0_x64_en-US.msi`.
- **macOS Apple Silicon and Intel:** `Agentdeck_0.15.0_universal.dmg` or
  `Agentdeck_0.15.0_universal.app.tar.gz`.
- `SHA256SUMS.txt` covers the four packages and `LICENSE`.

Windows installers are unsigned. macOS packages use the existing signing setup;
without Developer ID credentials they are ad-hoc signed and not Apple-notarized.

Close Agentdeck before updating. On Windows, keep the same installer type.
See the [chat and scheduling validation](https://github.com/arthurhpabreu/agentdeck/blob/main/docs/validation/2026-10-28-chat-ux.md)
for behavioral coverage and limits.
