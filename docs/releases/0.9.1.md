# Agent Deck 0.9.1

Released 2026-10-15.

New conversations use the project folder by default, avoiding a separate checkout
and duplicate dependencies for every chat. Choose **Create isolated worktree**
before starting a conversation when parallel changes need their own files and
branch. Conversations using the project folder share its files and local changes.

## Changes

- **Optional isolation:** the folder selector appears in the sidebar and welcome
  screen, remembers your choice and leaves existing conversations in their
  original directories. A failed isolation request shows an error before creating
  a conversation.
- **Visible disk usage:** Preserved worktrees shows the size of each checkout and
  eligible dependency/build caches, including registered folders from older
  installations. Development and release folders remain separate.
- **Targeted cache cleanup:** review and confirm the listed ignored `node_modules`
  and Cargo `target` folders to remove dependencies and build output while keeping
  source changes, other local files and branches. Resuming requires reinstalling
  dependencies or rebuilding.
- **Cleanup checks:** the app rechecks repository ownership, the commit and native
  session activity before deleting a selected cache. Locked or detached worktrees,
  tracked files, nested repositories and linked cache trees remain protected.

This update does not automatically delete existing folders based on age. Keep
worktrees for active isolated changes or local files that still need saving;
branches retain committed work without requiring a full checkout.

## Downloads

- **macOS Apple Silicon and Intel:** `Agentdeck_0.9.1_universal.dmg`, or
  `Agentdeck_0.9.1_universal.app.tar.gz`.
- **Windows x64:** `Agentdeck_0.9.1_x64-setup.exe` or
  `Agentdeck_0.9.1_x64_en-US.msi`.
- `SHA256SUMS.txt` lists checksums for the four packages and `LICENSE`.

Close Agent Deck before installing over the current version. On Windows, use the
same installer type (`.exe` or `.msi`).
