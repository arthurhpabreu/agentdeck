Agent Deck 0.6.7 adds optional Telegram notifications so you can receive a short completion alert on Android or iPhone/iPad.

- **Phone notifications:** connect your own Telegram bot in **Settings → System → Notifications** and enable **Also notify me on Telegram**. Automatic alerts follow the same successful main-response completion rules as desktop notifications, with duplicate events, progress, errors and interruptions filtered out. The main **Notifications** switch must also be on.
- **Simple pairing:** a private bot link pairs your Telegram conversation with Agent Deck. The pairing code expires after 10 minutes. **Send test** checks the connection explicitly, even when automatic alerts are disabled; **Reconnect** and **Disconnect** let you manage the saved connection.
- **Protected credentials:** the bot token is stored in the operating system's credential store after pairing. Messages go directly from Agent Deck to Telegram and contain no prompts, response content or project paths. The integration starts disabled and needs no Agent Deck server.

To set it up:

1. Open Telegram's official [@BotFather](https://t.me/BotFather), send `/newbot`, create a bot for Agent Deck and copy its token.
2. In **Settings → System → Notifications → Telegram notifications**, paste the token and click **Connect Telegram**.
3. Click **Open bot in Telegram**, press **Start** in the private conversation, then return to Agent Deck and click **I started the conversation**.
4. Enable **Also notify me on Telegram** and **Notifications**, then click **Send test**. Allow Telegram notifications on your phone and keep the bot conversation unmuted.

Telegram has official apps for [Android and iPhone/iPad](https://telegram.org/apps). The computer must remain awake, with Agent Deck running and internet access. See the [setup guide](https://github.com/arthurhpabreu/agentdeck/blob/v0.6.7/docs/setup.md#telegram-notifications) for credential replacement and disconnect details.
