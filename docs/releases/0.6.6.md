Agent Deck 0.6.6 reduces chat clutter, makes completion notifications predictable and improves local knowledge diagnostics.

- **Compact chat:** tool cards start closed, including running, failed and approval states. Open them by clicking the header or using the keyboard; incoming output preserves your choice. The redundant “Agent activity” disclosure is removed, and the inactivity notice waits two minutes.
- **Useful notifications:** one desktop notification after the main response finishes successfully and waits for your next message. Tool activity, intermediate progress, compaction, cancellations and duplicate completion events stay silent.
- **Consistent knowledge panels:** Documents uses the same scope selector, project controls and search styling as Shared Memory. Controls follow the current light/dark theme, and Settings switches work with the keyboard.
- **More project colors:** 18 presets, a native color picker and custom hex values. Click an existing project's color to edit it; canceling preserves its previous color.
- **Clearer vault diagnostics:** the per-note index limit increases from 256 KiB to 1 MiB. Partial indexes now explain whether notes were truncated, files or folders could not be read, or a specific limit was reached. The 3,000-note and 16 MiB total limits remain.
- **RTK with Codex:** the economy panel now shows both Claude and Codex integrations. Codex setup avoids duplicate inherited hooks, preserves explicit session hooks and refreshes RTK guidance when economy is re-enabled. The packaged adapter preserves command arguments and avoids double-prefixing RTK commands.

Codex can use RTK directly through the app's guidance. Automatic command rewriting additionally requires Execute mode with full access and native authorization in [`/hooks`](https://learn.chatgpt.com/docs/hooks#review-and-trust-hooks). An available adapter does not mean that Codex has trusted or executed it.

Validation evidence is recorded in [docs/validation.md](https://github.com/arthurhpabreu/agentdeck/blob/v0.6.6/docs/validation.md). Browser tests mock native commands; native protocol and packaged smoke tests do not make paid model requests.

Close Agent Deck and install over your current version using the same package type (`.exe` or `.msi`). Both Windows x64 installers are included with `LICENSE` and `SHA256SUMS.txt`. Installers remain unsigned.
