# Agentdeck 0.14.0

Agents can now coordinate automatically in an explicit team, including chats
from different projects. This release also fixes Codex sessions missing from the
subagent monitor.

## Changes

- **Teams across projects:** open **Project chats**, choose the participating
  chats and set a shared objective. The team shows each member's project,
  worktree, activity and summary, together with a shared conversation history.
  Automatic collaboration is optional and can be paused.
- **Automatic requests and replies:** agents can ask teammates for help and
  receive their replies without manually forwarding messages. Bound Codex and
  Claude structured chats can receive a supplement while working or resume for
  an eligible request or causal reply. Suspended, unbound, failed and recovering
  conversations are excluded from automatic wake-up. Gemini and native terminal
  chats receive queued context at their next supported hook boundary.
- **Cooperative file reservations:** agents can announce and reserve file or
  directory scopes before editing. Overlaps distinguish a shared checkout from
  changes that may conflict when worktrees are merged. Reservations expire and
  remain advisory; they do not lock files or prevent other tools from writing.
- **Confirmed delivery:** Codex RPC acknowledgements and Claude's native input
  UUIDs confirm structured-chat delivery. Writing to a local pipe alone does
  not count as acceptance. Uncertain delivery stays visible and is not replayed
  automatically. Team input preserves the user's draft, chat name and assigned
  task, and appears separately from messages written by the user.
- **Codex subagents visible again:** the monitor reads bounded native metadata
  larger than the previous 16 KiB cutoff and tracks delegation events from code
  mode. Windows session binding now uses startup and prompt hooks, with the
  existing completion callback as a fallback. Relationships still come from
  explicit native evidence.

Each chat keeps its selected knowledge sources, credentials, provider identity
and permissions. Joining a team shares coordination notes and activity; each
agent continues its own assigned work. Team messages and automatic turns are
bounded, and consume tokens on the participating agents. Routing does not launch
an additional coordinator model.

## Downloads

- **Windows x64:** `Agentdeck_0.14.0_x64-setup.exe` or
  `Agentdeck_0.14.0_x64_en-US.msi`.
- **macOS Apple Silicon and Intel:** `Agentdeck_0.14.0_universal.dmg`, or
  `Agentdeck_0.14.0_universal.app.tar.gz`.
- `SHA256SUMS.txt` is the checksum manifest for the four packages and `LICENSE`.

Close Agentdeck before installing over the current version. On Windows, use the
same installer type (`.exe` or `.msi`).
