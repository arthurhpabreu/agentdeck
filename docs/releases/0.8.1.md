# Agent Deck 0.8.1

This release adds selectable knowledge vaults, persistent visual organization and clearer attention, review and recovery workflows. Windows and macOS share the same version and application core.

## Changes

- **Selectable vaults:** register folders with any name, then select none, one or several for each project. Conversations can inherit the project or use their own selection; an empty custom selection means no shared vaults. Source modes, optional allowed folders/notes and explicit shared memory collections apply to automatic context and Agent Deck's memory tools.
- **Scope isolation:** legacy global sources enter the catalog without automatic project grants. Personal preferences require explicit approval of universal scope and project/conversation opt-in. Worktrees share the canonical project; ordinary clones remain independent. Migration preserves notes, IDs and history, with a verified association backup.
- **Lower streaming overhead:** stable session selectors, durable metadata projections, deduplicated saves and serialized atomic native writes avoid repeatedly persisting unchanged output. Up to four conversation and terminal views remain mounted per surface, preserving drafts, cursor/scroll and live processes.
- **Terminal flow:** one shared byte router, bounded batches, consumption acknowledgements and lossless per-run archives preserve Unicode/ANSI output. Large input yields between chunks, and explicit Cancel/provider changes retain process ownership.
- **Needs you:** confirmed questions, approvals, actionable failures and unread completions open the owning conversation. Passive authentication notices, terminal screen guesses and silence are excluded.
- **Diff review:** select a line or range, collect comments and send the complete review to a chosen project agent in one prompt. Changed diff references require review before sending; large diffs use bounded visible rows.
- **Contextual navigation:** Ctrl/Cmd+K includes project files, recent items, favorites and attention priority. Existing editor tabs are reused; local file/line references open in the editor and selected code can be added to the conversation draft.
- **Recovery:** distinguish restored history, confirmed provider resume and new conversations with context. Versioned checkpoints retain ten snapshots per conversation and list only metadata. New conversations use a fresh provider identity and reviewed context; legacy automatic archive references are removed from the proposed prompt, while preserving the original archive.
- **Visual organization:** drag projects, conversations, terminal/editor tabs, agents/subagents, map/board cards, files, source selectors, notes and other collections. Stable IDs preserve filtered positions and manual order across focus, streaming and restart. Keyboard movement, cancellation, undo, automatic order and display density are available.
- **Activity notice:** possible-stall recovery controls now appear after **four minutes without meaningful activity**. Heartbeats do not reset this timer. New OAuth warnings still expire after eight seconds and do not return from saved history.

## Downloads

- **macOS Apple Silicon and Intel:** `Agentdeck_0.8.1_universal.dmg`, or the equivalent universal `.app.tar.gz`.
- **Windows x64:** `Agentdeck_0.8.1_x64-setup.exe` or `Agentdeck_0.8.1_x64_en-US.msi`.
- `SHA256SUMS.txt` verifies the four packages and `LICENSE`.

The macOS application targets macOS 11+ with Safari/WebKit 16.4+. It is ad-hoc signed and not Apple-notarized; first launch can require Privacy & Security → Open Anyway. See [Apple's instructions](https://support.apple.com/en-us/102445). Windows installers remain unsigned.

## Context and recovery

Vault selection controls context and tools provided by Agent Deck. External MCP integrations, native global instructions and the provider's filesystem permissions retain their own configuration. Changing selection cannot erase content already delivered to an existing provider session; the sources panel keeps delivery evidence and offers a new conversation with reviewed context.

Native processes survive view eviction within the running application. App restart restores history/layout and resumable provider identities. PTY byte archives preserve output on disk; replay covers the active or last run during the application lifetime. They do not preserve a running process across an OS restart.
